# Kodland Camera

Fabric-мод для Minecraft 26.2: предмет «Фотоаппарат». ПКМ — снимок мира без HUD, поверх игры — полароид с двумя иконками: 🗑 удалить и ✓ сохранить. Сохранённое фото попадает в `kodland-photos/inbox/` — оттуда его забирает студия «Альбомы» в лаунчере.

Id мода в манифесте пака — **`kodland-camera`** (именно так, иначе студия «Альбомы» в лаунчере не появится). Внутри jar id — `kodland_camera`.

## Запуск локально

```bash
./run-dev.sh camera     # из корня репозитория
```

Первый запуск качает Gradle, Minecraft 26.2 и Fabric API — несколько минут. Открывается обычный клиент с ником `Player…`, аккаунт не нужен.

Сборка jar без запуска: `./gradlew :camera:build` → `camera/build/libs/kodland-camera-0.1.0.jar`.

Релиз: тег `camera-v<версия>` (версия — `mod_version` в `camera/gradle.properties`), см. README в корне.

## Как пользоваться

1. Создай мир в творческом режиме.
2. Открой инвентарь (`E`) → поиск → «Фотоаппарат» (или `Camera`). Он же лежит во вкладке «Инструменты и приспособления».
3. Возьми в руку, нажми ПКМ.
4. На полароиде: ✓ (или `Enter`) — сохранить, 🗑 (или `Delete`/`Backspace`/`Esc`) — выбросить.

## Где фото

`<папка игры>/kodland-photos/inbox/` — в dev-клиенте это `camera/run/kodland-photos/inbox/`.

На каждое фото два файла с общим id `yyyyMMdd-HHmmss-<6 hex>`:

- `<id>.png` — снимок 4:3, длинная сторона ≤ 1600 px;
- `<id>.json` — где и когда снято (версия контракта 1). Пишется последним: есть JSON — значит фото готово.

## Чек-лист проверки

- [ ] «Фотоаппарат» находится поиском в творческом инвентаре; рецепта нет (так задумано)
- [ ] ПКМ → на снимке нет HUD, прицела и руки; после снимка HUD возвращается
- [ ] Звук затвора и короткая белая вспышка
- [ ] Полароид слегка наклонён, под ним две иконки, текста нет
- [ ] ✓ → в `camera/run/kodland-photos/inbox/` появились `.png` и `.json`; в строке над хотбаром — «Фото сохранено!»
- [ ] 🗑 и `Esc` → ничего не появилось
- [ ] ПКМ чаще раза в секунду — лишних снимков нет
- [ ] 20 снимков подряд — FPS не проседает, игра не падает
- [ ] В Незере и Энде `dimension` = `minecraft:the_nether` / `minecraft:the_end`; `biome`, `pos`, `world.name` верные
- [ ] Если HUD уже был скрыт через `F1` — после снимка он остаётся скрытым
- [ ] Язык «Русский» и «English»: название предмета и сообщения переведены

## Устройство

| Файл | Что делает |
|---|---|
| `src/main/.../KodlandCamera.java` | регистрирует предмет и кладёт его во вкладку «Инструменты и приспособления» |
| `src/main/.../CameraItem.java` | ПКМ на клиенте → снимок; на сервере ничего |
| `src/client/.../CaptureController.java` | прячет HUD на 2 тика, читает кадр, возвращает HUD, открывает полароид |
| `src/client/.../PhotoImages.java` | обрезка 4:3, уменьшение до 1600 px, непрозрачность |
| `src/client/.../PolaroidScreen.java` | экран-полароид с иконками |
| `src/client/.../PhotoMeta.java` | метаданные снимка (контракт §3.1) |
| `src/client/.../PhotoWriter.java` | запись PNG → JSON через временные файлы, в отдельном потоке |
| `tools/gen-textures.py` | рисует пиксель-арт текстуры (`python3 camera/tools/gen-textures.py`) |
